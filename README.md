# Paper Reader

Paper Reader 是一款面向论文阅读的 **Windows x64 桌面应用**，将本地 PDF、批注、笔记、画布和 DeepSeek 问答放在同一个工作空间中。当前版本为 **0.2.0**。

界面由论文库、Reader / Summary 阅读区和 Chat / Note 助手区组成：阅读原文时可以提问、记录想法，再回到对应页核对来源。

## 阅读与整理

### 阅读 PDF、留下批注

- 导入本地 PDF，使用文字搜索、页码跳转、文件自带目录和缩略图定位内容。
- 高亮选中文字并添加评论，直接在 PDF 上圈画；支持颜色调整、整笔擦除和撤销 / 重做。
- 用手形工具平移页面，进入全屏阅读专注模式，或通过前进 / 后退返回本次会话中的阅读位置。
- 选中文字后，通过浮动菜单解释、翻译、概括或高亮；前三项使用 DeepSeek。

### 带着上下文提问、生成摘要

- 在 Chat 中选择 **当前页、全文、仅文字笔记、全文加文字笔记**，明确控制发送给 AI 的内容。
- 回答支持流式显示、Markdown、表格、代码和数学公式，可以取消请求、复制完整回答，并搜索当前论文的已保存对话。
- 在 Summary 中主动生成中文全文摘要，包含关键词、概览、背景、方法、结果和局限；来源页码可以跳回 PDF。
- 欢迎页提供独立的 **General chat**，无需打开论文。它保存一条通用会话，不附带论文内容。
- 对保存了原始请求的聊天或笔记整理，使用 **Retry original request** 复用当时的完整输入与模型，追加新一轮回答；改变当前页、笔记或模型不会改变这次重试的输入。旧对话可复用问题，编辑后按当前上下文发送。相同输入的 AI 回答仍可能不同。

### 用 Canvas 和思维导图组织想法

- 每篇论文有独立 Canvas，可以添加文字、PNG / JPEG 图片、手写笔迹、矩形、圆形、箭头与对象连线。
- 手工框选 PDF 区域，将原文图像加入 Canvas，并保留返回来源页的入口。
- 切换到 **Mind map**，编辑节点、添加子节点或同级节点、调整父节点和顺序；采用固定层级布局，支持撤销 / 重做。
- 将完整 Canvas 或思维导图导出为 PNG，便于保存和分享。

### 查看原图、表格和参考材料

- 在 Summary 中建立本地来源索引，查看图注、表题和参考文献候选，并跳到原文页。
- 原图区域从原始 PDF 页面预览开始，可以手工裁切、重新裁切或恢复整页。
- 从支持的文字表格布局中提取候选，保留原始数值字符串、表头、显式单位与来源文字，导出 CSV。
- 查看原始引文及解析字段，逐条主动查询 Crossref，比较标题、作者、年份等书目元数据。

### 写笔记、导出阅读成果

- 文字笔记、批注和手写按论文保存；Note 中还提供独立手写板。
- AI 整理笔记先生成建议，经过查看、编辑和确认后才追加或替换原笔记。
- 导出 Markdown 阅读笔记，包含文字笔记、高亮原文与评论、已保存摘要及来源页码。
- 导出带批注的 PDF 副本，保留正文，并加入高亮、PDF 圈画和评论。原始 PDF 不修改，导出使用新文件名。

### 管理论文库

按导入日期或自定义分类浏览论文，搜索标题、作者、年份和分类；手工编辑论文标题、作者与年份。论文的阅读资料各自保存，欢迎页通用聊天独立于论文会话。

## 快速开始

1. 保留完整的 `PaperReader-0.2.0-win32-x64/` 便携目录，双击其中的 `PaperReader.exe`。升级时先正常关闭旧版，再启动新版。
2. 点击 **Import a PDF**，打开自己的论文；也可以先浏览明确标注的演示内容。
3. 阅读、批注、写笔记和使用 Canvas 无需 DeepSeek Key。要使用 AI，在 **Settings** 中输入自己的 DeepSeek API Key 并保存，可调整模型名称。
4. 提问前检查输入框旁的 **AI context**；生成全文摘要时，在 Summary 中点击 **Generate summary**。

详细操作见 [0.2.0 使用指南](docs/2026-10-08-v020-guide.md)。

## 本地数据与在线服务

导入时，应用会把 PDF 复制到本机应用数据目录；论文、笔记、聊天、批注、摘要与画布也保存在本机，与便携程序目录分开。原始导入文件保持不变。API Key 在本机加密保存；加密不可用时会提示错误。保存的原始 AI 请求包含发送过的文字内容，不包含 Key。

PDF 阅读、搜索、批注、Canvas、来源索引、表格和引文解析在本地完成。调用在线服务的范围如下：

- **DeepSeek 问答**发送问题与所选文字上下文。当前页、全文及全文加笔记模式还会附带有界的近期聊天；仅笔记模式只使用当前 Text 笔记，不带论文正文或近期聊天。
- **全文摘要**发送提取的全文文字，长文可能使用多次请求；**笔记整理**发送当前 Text 笔记；**General chat**发送问题与该独立会话的近期聊天。
- **Crossref 查询**仅在逐条点击 **Verify with Crossref** 时发送选中的引文文字或 DOI，需要联网，无需 DeepSeek Key。

演示论文、摘要和对话均标为示例。在线 AI 的生成结果需要结合原文核对，页码链接有效也不代表论断正确。

## 当前范围

- 支持可提取文字的 PDF；扫描件尚无 OCR。全文问答和摘要最多处理 200 页、240,000 个提取文字字符，AI 文字笔记输入最多 100,000 字符。
- 尚无图像理解、自动识别精确图框、跨论文检索或云同步。原图裁切与 PDF 区域捕获都需要手工选择。
- 表格和引文解析有格式边界，结果以候选及原文呈现；复杂表格布局可能无法重建。Crossref 的书目匹配不验证科学结论，未找到记录也不代表文献无效。
- AI 笔记上下文只包含 Text；Canvas、思维导图、手写和高亮评论不进入该上下文。Markdown 阅读笔记不包含画布或手写图像。
- Canvas 使用固定 1000×1200 画布，思维导图使用有数量和层级限制的固定布局。欢迎页目前只有一条通用会话，未发送草稿仅保留在本次会话中。

## 本地开发

项目使用 Electron、React、TypeScript 和 PDF.js。使用兼容的 Node.js 24 与 npm，在项目目录运行：

```powershell
npm ci
npm run dev
```

生成 Windows x64 便携目录：

```powershell
npm run package
```

输出为 `dist/PaperReader-0.2.0-win32-x64/`，运行其中的 `PaperReader.exe`，并保留整个目录。项目约定见 [AGENTS.md](AGENTS.md)。
