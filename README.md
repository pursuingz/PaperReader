# Paper Reader

Paper Reader 是一款 Windows x64 本地论文工作空间，将 PDF 阅读、AI 问答、文献管理、笔记和可视化整理放在一起。当前版本为 **0.4.0**。

在同一个 Chat 中，可以讨论论文，也可以直接交代任务：寻找并导入文献、整理分类、批量生成阅读成果，再把选定内容导出。

## 论文有统一的归处

导入与在线获取的 PDF 保存到你选择的 **Papers 文件夹**。论文库支持按最近阅读时间或类别浏览，以及编辑题名、作者和年份；批量任务直接在 Chat 中描述对象和范围。

- 通过论文右侧的 `… → Show in File Explorer` 定位文件。
- 扫描手动放进文件夹的 PDF，并选择导入。
- 将早期版本的论文复制、核对并关联到统一目录，保留原副本和原有阅读记录。
- 原始 PDF 平铺保存，笔记、批注、Canvas 资源与阅读记录保存在独立的应用数据目录。

## 用 Chat 完成研究任务

无需切换 Ask / Agent 模式。提问直接获得回答，明确的操作指令进入任务执行。

可以这样使用：

> 找到并导入这篇论文，检查论文库里是否已有相同文件。
>
> 把库内的论文按研究方向分类，保留已有分类。
>
> 为 Neural Rendering 类别中的论文生成英文 Summary 和中文阅读笔记。
>
> 导出指定论文的 Canvas、Mind map、带批注 PDF 和阅读记录。

回答沿用正常 Markdown，并支持流式显示。工具过程归属对应问题，默认以可展开的一行活动呈现；生成的文件、论文和笔记在回答旁提供结果入口。任务支持取消、查看历史与继续，切换阅读页面后仍能找回后台成果。

联网查找与下载使用 **arXiv**。找到确定匹配后自动获取 PDF 并入库，内容重复时复用已有论文。arXiv 中没有匹配时显示 `paper unavailable`；网络故障与下载失败提供重试原因。

Summary 的 **References** 每条引用提供 **Find on arXiv**，可以直接寻找、获取并导入引用论文；已有论文则提供打开入口。

## 阅读、理解与记录

- 本地 PDF 搜索、目录、缩略图、页码跳转、平移和全屏阅读；支持选文解释、翻译与概括。
- 高亮、评论、PDF 手写及撤销 / 重做；可导出带批注副本。
- Chat 保留 Current page、Whole paper、Notes only、Paper + notes，并增加 **All library papers**。全库模式先查看元数据，再按问题读取相关论文。笔记来源包括 Text、Highlights、Mind map 和 Canvas；截图可加入聊天、复制、保存或放入 Canvas。
- Summary 支持英文和中文，按 Keywords、Overview、Background、Methods、Results、Limitations 组织。长论文先分块阅读，再统一成文；失败后可继续，并保护旧摘要。
- 新生成的阅读笔记保存为独立草稿，可查看、复制、导出或追加到 Text。已有 Text 可以保真整理并审阅建议。

## 把想法放到画布上

Note 提供并列的 **Text、Highlights、Mind map、Canvas**。

Text 支持可视化 Markdown 编辑与源码模式。Canvas 提供多页无限画布、富文本框、图片、摘录卡片、手写、图形与连线；支持移动、缩放、颜色调整和直接编辑。高亮与导图可以复制到 Canvas，保留来源和独立编辑能力。

| 内容 | 导出格式 |
| --- | --- |
| 原论文、带批注论文 | PDF |
| Canvas | PNG、PDF |
| Mind map | PNG、PDF、层级 Markdown |
| Text、Summary、新生成阅读笔记 | Markdown |
| 含笔记、高亮评论与摘要的阅读记录 | Markdown |

## 本地语音与手势

Chat 输入框右侧提供麦克风按钮。首次下载或导入多语言模型后，可在本地识别中文、英文，识别结果会在说话过程中逐段更新到输入框，保留原有草稿。录音时点击发送，会提交当前句并继续录制新的语音段；再次点击麦克风停止，保留当前文字供编辑。

手动开启摄像头后，画面显示在可拖动、可缩放的应用内悬浮框中；操作说明弹窗分项介绍六项动作，输入框保持紧凑：

| 动作 | 功能 |
| --- | --- |
| 食指静止指向右 / 左，其余手指收起 | 上一页 / 下一页 |
| 食指静止指向上 / 下，其余手指收起 | 向上 / 向下滚动，保留文字重叠 |
| 手背朝向摄像头，仅伸出大拇指 | 开始语音输入 |
| 手背朝向摄像头，同时伸出大拇指和食指 | 结束识别并发送转写文字 |

语音和手势在本地处理。摄像头需要显式开启；操作说明、拖动和缩放时暂停手势，关闭预览会停止摄像头。动作包含停留和重复触发保护。实际识别效果会受设备、光线、噪声和发音影响。

## 开始使用

完整解压 Windows 程序包，运行 `PaperReader.exe`，并保留整个目录。

1. 选择 Papers 文件夹，导入论文；早期版本用户可在 **Papers folder** 中整理已有 PDF。
2. 在设置中填写自己的 DeepSeek API Key。
3. 阅读、提问，或在 Chat 中描述需要完成的任务。
4. 需要语音时下载 / 导入本地模型；需要手势时手动开启摄像头。

论文文件与本地阅读数据分别保存。AI 请求会按任务发送必要材料；本地语音不把原始录音发送给 DeepSeek。API Key 由主进程加密保存。论文、模型缓存与使用记录不属于源码。

扫描件 OCR、付费全文获取、跨设备同步和可编辑 PDF 图形批注不在当前支持范围。页码链接用于定位原文，AI 内容仍需结合论文判断。

详细操作见 [0.4.0 使用指南](docs/2026-10-28-v040-guide.md)。

## 从源码运行

需要 Windows x64、Node.js 和 npm。

```powershell
npm ci
npm run prepare:input
npm run dev
```

构建便携程序：

```powershell
npm run typecheck
npm run package
```

本地推理运行文件由准备命令按固定版本获取。输出位于 `dist/PaperReader-0.4.0-win32-x64/`。项目结构与工程约定见 [AGENTS.md](AGENTS.md)。
