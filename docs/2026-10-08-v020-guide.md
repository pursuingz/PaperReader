# Paper Reader 0.2.0 使用指南

本指南介绍 Paper Reader 0.2.0 的 Canvas 图形、思维导图、欢迎页通用聊天和原始请求重试。PDF 导入、基础阅读与 DeepSeek 设置见[项目介绍与快速开始](../README.md)。

应用采用论文库、阅读区和助手区组成的三列布局；论文、笔记、聊天与画布保存在本机。

## Canvas 图形与关系

打开真实论文 → Note → Canvas。基础文本、图片、笔迹仍使用原工具；新增 Rectangle、Circle、Arrow。选择图形后可调整位置、大小、颜色和线宽；自由箭头两端可独立拖动。

选择 Connection 的两个对象及锚点后连接，可连接基础文本、图片与新形状。移动对象时线段随之调整。笔迹不能作为连接端点。移除端点后保留关系记录，撤销恢复端点时连接再次可见。

基础画布和图形层分别使用各自标明的 Undo／Redo。PNG 导出包含完整画布与图形层，不包含选框或工具。使用原生保存窗口和新的 PNG 文件名；不覆盖原有文件。

## 思维导图

Canvas 顶部切换 Mind map。选择根节点，编辑文字；Add child 和 Add sibling 增加层级。Parent 控件调整父节点，Earlier／Later 调整同级顺序，Remove subtree 移除节点及其后代。可撤销／重做。

导图使用固定层级布局，自动计算整个图的范围。布局、层级和节点数量都有上限；越界修改会被拒绝并保留已有导图。导图与基础画布、图形层独立保存。Export mind map PNG 导出整个导图；当前窗口仅显示一部分不会裁掉其他节点。

## 欢迎页独立聊天

返回 Home，使用右侧 General chat。它是一条独立的本地会话，无需打开论文；发送问题与有界近期聊天给 DeepSeek，不附带论文正文、选区、笔记或画布。

支持 Enter 发送、Shift+Enter 换行、流式预览、取消与复制完整回答。流式片段不保存，完成后才保存助手回答。切换到论文和关闭前取消当前请求并等待保存。保存失败时显示提示，完整回答保留在会话中，可 Retry saving；读取失败保持原数据受保护。

欢迎页草稿与每篇论文草稿在本次会话中分别保留，重启不恢复草稿。当前仅有一条欢迎聊天，不提供多会话管理。

## 重试原始请求

从此版本（现名 0.2.0）开始，真实论文聊天、笔记整理和欢迎聊天在联网前保存完整最终请求，包括当时模型、系统指令、消息、发送范围、流式模式和输出预算。快照不包含 API Key。

问题下点击 Retry original request，会追加标明 Retried round 的新一轮。原有回答与当前输入草稿保留；即使更改页码、选区、笔记、近期聊天或当前模型，仍发送保存的原始输入。重试使用当前配置的安全保存 Key，不会自动切换当前阅读页面。

笔记整理重试仍是建议，不修改原笔记。旧聊天和演示聊天没有完整快照，显示 Original request unavailable；论文旧问题仍可 Reuse question 后自行编辑发送，此操作使用当前上下文。

取消、失败或重启打断的快照保留，重启不会自动发送。界面显示 pending、response-ready、completed、failed、cancelled 或 interrupted；completed 只有在完整回答实际保存且与保留的消息标识／内容哈希匹配后成立。历史文件有异常时显示独立错误和 Retry request history，本地阅读与已保存聊天保留。

## 范围与限制

- 图形和导图不加入 AI 的文字上下文；不提供自由布局、自动生成图或图像理解。
- Canvas 固定 1000×1200，PNG 为 2000×2400；导图 PNG 最多每边 4096 像素、1600 万像素、10 MiB。
- 每条聊天最多 1000 条消息，发送前为完整回答预留名额。欢迎问题最多 16000 字符，论文问题最多 20000 字符，完整回答最多 200000 字符。
- 请求快照单个最多 4 MiB，历史清单最多 1000 条／1 MiB，每个作用域合计最多 128 MiB（包含保留的恢复文件）。达到限制时拒绝新请求，不清理旧数据。
- OCR、图像问答、跨论文检索、云同步、多欢迎会话、整库备份、正式安装器仍未实现。

运行 `dist/PaperReader-0.2.0-win32-x64/PaperReader.exe`。保留整个目录，先正常关闭旧版再启动新版；原有软件数据目录保持不变。
