# Paper Reader 0.3.1 使用指南

## 启动与原 PDF 文件夹

完整解压后运行 PaperReader.exe，保留整个程序目录。Papers folder 显示当前原PDF目录；本次便携包沿用已确认的外部 Papers 配置，可用 Choose folder 调整。

新导入、下载的原PDF直接平铺保存，不为每篇论文创建附加资料子目录。Text、聊天、批注、Summary、Canvas图片/手写、Mind map和任务记录保存在应用数据目录，按稳定论文ID关联。下载暂存和语音模型也不混入Papers。导出时另选输出目录，导出结果可以按论文建子目录。

Consolidate existing papers 会复制旧内部原件或旧外部目录已关联的原件到当前Papers，校验后更新位置；保留原文件、论文ID及已有阅读资料。启动不会自动归并，更换目录也不会立即搬移。失败项保留原状。程序不会自动清理目录里原有的其他文件。

Scan PDFs 可扫描手动放入的PDF，勾选扫描结果后 Import selected。论文侧栏不再有常驻多选框。相同内容复用已有条目，不同版本按任务提示处理。

论文右侧省略号保留 Show in File Explorer。Locate original PDF 已移除；外部移动或改写原件后会显示不可用，已有笔记保留。

## Chat 与上下文

欢迎页和论文页使用统一Chat。普通问题直接回答；明确的操作指令由工具执行。

论文页保留全部四个原选项并增加全库：
- Current page：当前页，默认值。
- Whole paper：当前论文全文。
- Notes only：选定的Text、Highlights、Mind map、Canvas等笔记来源。
- Paper + notes：当前论文与选定笔记。
- All library papers：库内所有论文，先检索元数据，再按问题读取必要论文。

欢迎页可以选择 General question 或 All library papers。全库不会预先拼接、发送所有论文全文；发送时固定任务范围，随后阅读其他论文不改变正在执行的任务。通用/单篇模式不会隐式读取其他库内论文。明确下载任务的成功导入回执可以让Agent继续阅读刚获取的论文，以完成后续解释等要求；不会因此开放无关私人笔记。

要批量处理时，在Chat中指定题名、类别或范围，例如：

> 在 All library papers 下，把库内与 neural rendering 相关的论文归入一个类别，保留已有分类。
>
> 找到并导入这篇 arXiv 论文，再解释它的方法。
>
> 为 Neural Rendering 类别中的论文生成英文Summary和中文阅读笔记。
>
> 导出这些论文的全部Canvas、Mind map、带批注PDF和阅读记录。

模型回答使用原有Markdown风格并流式显示。每个问题下面的一行活动可展开查看过程；论文、文件和笔记结果归属这轮。完成的普通问答不再额外堆叠Succeeded卡片。完整路径和诊断信息留在详情，不作为固定正文追加。

History 主动打开历史任务，包括早期版本无法精确关联的旧任务。旧聊天不会被猜配、重写或删除。

## 取消、继续与重新回答

Cancel task 停止后续工作，已完成的保存保留。Continue task 继续未完成的任务；重启后不会自动联网或调用AI，需手动继续。

Answer again 使用保存的模型、来源快照和已完成结果，追加一个新的回答轮次；不会重新读取当前论文/笔记，也不会再次执行导入、分类、生成文件或导出。输入框中未发送的草稿保留。未完成的操作仍需 Continue task；重新回答不会把未确认工作说成已完成。

旧原请求的 Retry original request 保留原有兼容行为。没有原快照或精确关联的旧记录不能补造来源，可复用问题重新提问。

后台任务完成、切换文档或继续任务后，回到原聊天即可看到保存的答案和结果；任务不会为了处理另一篇论文而切换当前阅读器。

## 从 arXiv 查找并导入

References 的 Find on arXiv 与Chat共用获取流程。现代/旧式arXiv ID优先精确定位，引用原文中的ID也会识别；有完整题名时核对标题、已知作者、年份和标识符。缺DOI或 et al. 作者缩写本身不构成冲突。

确定匹配后直接下载官方PDF、校验并入库，成功提供Open paper。重复内容复用已有论文；明确版本按指定版本处理，同一作品未指定版本默认最新。真正不同作品难以区分时，在本轮选择目标。

arXiv内没有匹配作品显示 `paper unavailable`。网络故障、限流、超时、非PDF响应或损坏文件会给出失败原因和重试入口，不假装成论文不存在。程序不从其他论文站点补找全文，也不绕过访问限制。

## 生成与文件结果

Summary沿用六模块、英文/中文和旧摘要保护；长论文分块阅读后整合。扫描页仍需文字层/OCR，全文处理上限200页、240000字符。

新阅读笔记保存为独立草稿。View notes 可查看、复制、导出Markdown或Append to Text；追加前核对当前Text，冲突时保留草稿。Organize with AI仍处理已有笔记，保留审阅流程。

文件结果通过View files查看短文件名，支持Open和Show in folder；打开前核对已保存的文件身份。文件外部移动或改写后不会静默打开其他内容。导出采用新文件名，保留已有原件与导出。

| 内容 | 格式 |
| --- | --- |
| 原论文、带批注论文 | PDF |
| Canvas各画布或指定范围 | PNG、分块PDF |
| Mind map | PNG、分页PDF、层级Markdown |
| Text、Summary、独立阅读草稿 | Markdown |
| Text、高亮评论与Summary组成的阅读记录 | Markdown |

Markdown不完整保存Canvas的图片、手写和空间布局，需要视觉布局时使用PNG/PDF。

## 本地语音与摄像头悬浮框

麦克风和摄像头开关位于输入框右侧。语音首次下载或导入约148MB的多语言模型，之后可离线识别中文/英文。普通麦克风停止后只转写到草稿，保留原文字；每次录音最长3分钟。

开启摄像头会出现独立于输入框的应用内悬浮框和操作说明Modal。拖动标题栏移动，拖动边角缩放；缩小主窗口时预览保持可见。视频保留完整画面，采用镜像。预览的说明按钮可以再次打开指南，关闭预览同时停止摄像头与推理。

六项手势：
1. 张开手掌向右挥：上一页。
2. 张开手掌向左挥：下一页。
3. 伸出食指向上移动：向上滚动。
4. 伸出食指向下移动：向下滚动。
5. 手背朝向摄像头，仅拇指伸出、其他四指收起，保持约0.7秒：开始录音。
6. 录音中手背朝向摄像头，拇指与食指伸出、其他三指收起，保持约1秒：停止、完成转写并发送。

动作后回到中立姿势。说明弹窗、拖动/缩放、窗口不在前台或识别中断时暂停手势。结束发送只作用于当前录音；论文、上下文或草稿发生变化时保留文字供检查，不发送到其他会话。

语音和摄像头画面用于本地推理，不作为原始媒体发送给DeepSeek。识别准确率和速度仍取决于设备、光线、噪声及发音。

## 数据与使用边界

DeepSeek在你发送或发起生成时接收所需材料；arXiv检索接收查询或引用信息。API Key由主进程加密保存，不进入聊天任务记录或源码。

AI的解释、分类与Summary需要结合原文判断。PDF、网页和笔记是资料，不是给Agent的权限指令。程序不提供任意命令执行、自动删除、付费全文获取、OCR、云同步或可编辑PDF图形批注。
