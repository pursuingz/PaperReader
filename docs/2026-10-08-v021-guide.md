# Paper Reader 0.2.1 使用指南

## Note 的四个入口
Text、Highlights、Mind map、Canvas 并列。Text 的文字笔记、AI 整理和 Markdown 导出保持原有范围。Ink 页签已移除；旧笔迹文件保留，可从 Canvas 显式导入旧笔迹。

## 摘录与导图加入 Canvas
Highlights 每项的 Add to Canvas 复制当时的原文、评论和来源页，加入当前页；Canvas 中的评论独立编辑，原 PDF 高亮不变。来源页按钮返回论文页面。
Mind map 的 Add to Canvas 复制整个导图为可编辑的节点与连线组。可移动、缩放及编辑节点文字；原导图独立保存，不双向同步。Mind map 保留原有完整 PNG 导出与展开编辑。

## Canvas 编辑
添加文字、PNG/JPEG 图片、手写笔迹、图形和连线。选择对象后移动，使用手柄调整宽高；双击文字框编辑。文字支持标题、段落、列表、加粗、斜体、下划线、颜色与背景高亮。
文字编辑时自动切换到可读倍率；完成后可在 Pen, shapes & zoom 中切回 Fit。输入空闲时自动保存，离开页面前提交当前输入。
原文摘录与个人评论分别显示。文字溢出时可使用 Fit content 调整框高；图片缺失、越界线条或缺少端点的连接会阻止 PNG 导出，先修复内容再导出。保存失败会保留当前编辑。

## 多页与页面尺寸
每篇论文有独立的 Canvas 笔记本。Pages & size 内可新增、命名、复制、排序和设置尺寸；上方页签切换页面。页面默认 1000×1200，宽高各支持 256–4096，最多 50 页。
Pen, shapes & zoom 内有笔宽、颜色、擦除、平移、图形和倍率；Import legacy ink 复制原 Ink 内容到独立新页。
调整尺寸不缩放已有内容。缩小时如果内容越界，操作会拒绝，原页面保留。Expand 扩大编辑视窗，页面尺寸设置改变实际文档。
PNG 导出当前完整页面；标准页仍为 2000×2400，大页按最长边4096像素及1600万像素限制调整倍率。导出保留富文本、摘录、导图组、图形与笔迹，使用新文件名。

## 本地兼容
已有 Canvas 与图形会作为首个页面读取。新版实际编辑保存到新增的 canvas-notebook.json，原文件和图片资源保留。旧 Ink 需要手动复制导入，不自动转换。
旧版0.2.0只能读取原有格式，看不到新版新增的多页内容。先正常关闭旧版，再运行新版，避免同时编辑不同格式的记录。
读取损坏时保护已有文件并提供重试；关闭、切换论文或导出前会保存编辑。

## 当前范围
Canvas 内容仍不加入 AI 的文字上下文或 Markdown 阅读笔记。图片和手写没有 AI 识别能力。
本轮不新增 OCR、局部擦除、云同步、整库备份及跨论文检索。撤销为有界会话记录。
本地运行 dist/PaperReader-0.2.1-win32-x64/PaperReader.exe，保留整个程序目录。
