# Paper Reader 0.3.2 输入操作指南

完整解压后运行 PaperReader.exe。保留整个程序目录；已有论文、笔记、聊天及原PDF目录设置继续使用，不自动搬移或清理数据。原PDF目录可在Library底部 Papers folder 查看。

## 静态方向手势

开启摄像头后出现悬浮预览和操作指南。首次先让整只手张开、手指朝上，短暂完整入镜建立跟踪，再只伸出食指指向方向；不再需要挥动。向下姿势漏检时，可先让食指竖直朝上短暂停留建立跟踪，再指向下；不必等待向上指令触发。方向以镜像预览为准。

| 姿势 | 操作 |
| --- | --- |
| 食指向上，其余手指收起 | 向上滚动 |
| 食指向下，其余手指收起 | 向下滚动 |
| 食指向左，其余手指收起 | 下一页 |
| 食指向右，其余手指收起 | 上一页 |

保持约0.6秒触发一次，持续摆着不会连续翻页；每次之后回到自然姿势至少0.25秒，指令间隔至少0.9秒。对角或难以确定的姿势不触发。阅读器尚未加载或在Summary页面时，方向指令不翻动PDF。

滚动根据可见阅读区高度、当前缩放和PDF文字行位置重新计算，至少保留三行文字重叠，并为双栏和边缘半行留余量。扫描图片页没有可测文字行时保留保守画面重叠，不能据此判断图中的真实行数。

语音手势保留：手背朝向摄像头、仅拇指明显向掌外展开，保持约0.7秒开始录音；录音中拇指与食指伸出、其他三指收起，保持约1秒结束转写并发送。食指导航时拇指收回，避免误触发送。

弹窗、拖动/缩放预览、失去焦点时暂停手势。预览可移动缩放，关闭即停止摄像头；视频和关键点仅在本地处理。

## 边说边输入

首次使用语音需要准备本地多语言模型，输入区会显示Download/Import入口。语音模型与手部模型独立；摄像头可用不表示语音模型已经准备好。

点击麦克风开始录音，音量条显示输入活动。识别结果直接写入当前Chat输入框，保留原有草稿；后续结果替换同一段临时文字，停止后的最终文字不会再次追加一遍。欢迎页和论文页均支持。

本地模型按短音频窗口更新，首次需要积累约2秒音频并完成推理，之后间隔由处理速度调整；这是逐段更新，不能保证每个字零延迟出现。结束时会处理尾部音频。

点击麦克风停止，只保留文字到草稿；只有约定的结束手势会尝试发送。取消保留已经识别的文字。手动编辑、切换论文或改变上下文后，不自动覆盖编辑或发送到其他会话；无法安全替换的最终结果另行保留到原草稿。

若音量条没有活动，检查Windows选定的麦克风及输入音量；无设备、权限拒绝、模型缺失、没有信号、未识别出语言及本地引擎错误会分别提示。中文或英文识别不稳时，可在语言下拉中明确选择。

## 范围

本次保留0.3.1的arXiv导入、统一Chat、全部上下文选项、悬浮摄像头与平铺PDF功能。未更改持久化格式、凭证或云服务。真实光线、手势角度、麦克风噪声和设备算力仍影响识别；离线测试不代替实际硬件准确率验收。
