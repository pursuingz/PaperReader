# Paper Reader 0.2.2 使用指南

## 多页无限 Canvas
Note 的 Text、Highlights、Mind map、Canvas 继续并列。Canvas 内每张画布独立命名、复制、排序与保存，可以向上下左右扩展；原来的宽高设置已移除。
文字框、图片、手写、摘录、导图副本、图形与连线继续使用。缩放和移动视野不会改变对象本身的坐标或大小。

## 移动与缩放
使用 Hand 工具、鼠标中键拖动，或按住空格拖动移动视野。滚轮围绕鼠标位置缩放；编辑文字时空格保持正常输入。
Fit all 显示全部内容，Focus selected 找到选中对象，Reset zoom 恢复正常倍率。侧栏和 Expand 大视窗均可使用；每张画布独立记住视野。
在当前视野添加新对象、导入图片/摘录/导图，内容会放在附近。文字编辑支持原有富文本、移动、缩放与 Fit content。导入的评论和导图保持独立副本。

## 选择导出范围
导出时选择全部内容、当前视野或框选区域，再选择 PNG 或 PDF。框选区域可以在任意坐标绘制；轮廓表示导出边界。
PNG 输出有限尺寸图片，最长边最多4096像素，总像素最多1600万，最多10MiB；大范围会按比例缩小。
PDF 把选定范围按从左到右、从上到下分成多页，每块最多1200×1600画布单位，单次最多50块。范围过大时缩小选择后重试；PDF 是画布视觉副本，不包含可编辑对象层或可搜索文字。
文字溢出、图片缺失和悬空连线会阻止导出，先修复后再保存。每次使用新文件名，原论文与既有导出不被覆盖。

## 兼容与保存
旧 Canvas、0.2.1 多页笔记和旧笔迹可继续读取。无限画布保存到新增 canvas-infinite.json；旧文件与图片资源保留，不转换或覆盖旧版文件。旧笔迹可显式复制到独立画布。
旧版程序看不到新版无限画布的新编辑；升级前先正常关闭旧版。新格式读取失败会保护原文件并提供重试，不自动用空画布覆盖。
视野和编辑自动保存在本机；撤销历史仍只保留于当前会话。没有固定页边界，仍有对象、笔迹、资源和坐标精度保护，以保证本地运行稳定。

## 当前范围
Canvas、导图、图片和手写仍不进入 AI 文字上下文或 Markdown 阅读笔记。OCR、视觉理解、云同步与整库备份不在本轮范围。
运行 PaperReader-0.2.2-win32-x64/PaperReader.exe，保留完整程序目录。旧组件的清理只涉及被替代的界面代码，不删除个人论文、笔记或资源。
