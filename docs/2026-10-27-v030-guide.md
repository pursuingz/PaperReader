# Paper Reader 0.3.0 使用指南

## 首次启动与文件位置

完整解压程序包后运行 PaperReader.exe。程序目录包含本地运行资源，请保留整个目录。论文和个人阅读数据不需要放在程序目录中。

Papers folder 显示当前统一论文目录，可以通过 Choose folder 选择其他位置。此目录保存新导入、在线下载的 PDF；笔记、批注、摘要、聊天和任务记录仍保存在应用数据目录，并按原论文 ID 关联。更换目录不会自动移动已关联的论文。

早期版本用户可选择 Consolidate existing papers：程序复制现有内部 PDF，核对内容后登记新位置，保留原文件。失败项会列出，不会删除原件或重建原来的笔记。这个操作由用户显式触发，启动时不会自动整理旧库。

Scan PDFs 用于发现手动放入目录的 PDF。勾选后点击 Import selected。相同内容复用已有条目；不同内容、同一标识符的版本需明确选择。Show in File Explorer 位于论文右侧的省略号菜单。

外部移动文件后使用 Locate original PDF。重新关联只接受与原内容相同的 PDF，避免旧批注落到另一篇论文上。

## 统一 Chat

欢迎页和论文页均可输入问题或任务，不存在 Ask / Agent 开关。论文页保留当前页、全文、笔记等上下文选择；欢迎页不会自动附加某篇论文的全文。

Library 的复选框用于选择一批论文。无选择时，Chat 可按你的任务查找论文库；有选择时，以显示的选区为任务范围。发送时冻结范围，随后修改复选框或切换阅读文档不会改变已发出的任务。

普通问题直接回答；明确的搜索、下载、分类、生成或导出指令调用相应工具。任务卡显示实际步骤、待选候选、成功或未完成回执。Show older tasks 可查看更多历史。取消会停止后续工作，已经完成的保存会保留。中断或重启后可显式 Continue，不会自动发起联网或付费请求。

单次任务有资源预算，默认最多50个目标论文。更大任务可分批执行；达到预算会保留已完成成果，显示剩余状态并提供继续入口。

示例：
- 检查选中的论文，按研究方向分类，保留已有分类。
- 建立一个新的研究类别，找出库内相关论文并归类；不确定的先列出来。
- 搜索并导入指定题名或 DOI 的论文。
- 为选定论文生成英文摘要与中文阅读笔记。
- 将这些论文的所有 Canvas 画布导出 PDF，再导出 Mind map 和阅读记录。

自动分类会保留已有类别；若要修改已分配类别，请明确要求重新分类。

## 搜索、版本与 References

联网结果来自真实学术来源与公开原站。候选含题名、作者、年份、标识符及来源。书目信息存在不代表 PDF 可以获取。

References 每条引用的 Find & import 会检索、核对、下载并导入。唯一明确匹配可继续获取；歧义候选需要选择。不同版本会提示保留旧版并确认新版本。已导入结果可直接打开。未能获取全文时保留来源入口，可自行取得 PDF 后本地导入。

## Summary 与新阅读笔记

Summary 保留六个模块和英文 / 中文选择。短论文直接成文，长论文分块阅读后整合。没有文字层的扫描页目前需要外部 OCR；全文处理上限200页、240000字符。旧摘要受到保存保护，失败后可继续已完成阶段。

“生成阅读笔记”根据论文形成新的独立草稿；“整理笔记”处理已有 Text。两者不同。任务结果的 View notes 可以查看、复制、单独导出 Markdown，也可以 Append to Text。追加前核对版本，不会替换个人笔记；冲突时保留独立草稿以便稍后处理。

## 导出

每次批量导出选择一次输出目录，再按论文创建独立结果目录。程序采用新文件名，不覆盖 PDF 原件、以前导出或应用内部数据。导出目录应在 Papers 目录以外。

- Original / Annotated：原始或带批注的 PDF 副本。
- Canvas：选定画布的 PNG，或包含全部内容的分块 PDF。
- Canvas viewport / region：从当前实际打开的画布视口或选中区域取得范围；不对应当前视图时会要求选择范围，可改用全部内容。
- Mind map：PNG、分页 PDF 或节点层级 Markdown。
- Text、Summary、独立阅读草稿：各自的 Markdown。
- Reading record：合并 Text、高亮评论与已保存 Summary 的 Markdown。

Markdown 不能完整保存画布的图片、手写和空间布局。需要完整视觉内容时使用 PNG / PDF。

## 语音输入

麦克风位于输入框右侧。首次使用点击 Download 下载固定版本的多语言模型，或 Import 导入对应模型文件。录音可选自动、中、英语言。模型保存在应用的本地模型目录，不混入 Papers。

点击麦克风开始，再次点击停止并转写到草稿。输入框中的原有文字保留，可编辑后发送。每次录音最长3分钟；处理速度取决于本机性能。空录音、识别失败和上下文变化不会自动发送问题。导航前会先结束本地识别并把可用文字保留在原聊天草稿。草稿是会话内状态，关闭程序前请发送或复制需要保留的文字。

普通麦克风停止只进入草稿；指定的结束手势才会在完成最终转写后尝试发送。发送前若论文、页面、笔记上下文或输入草稿已经改变，会保留文字供检查。

## 摄像头手势

手动点击摄像头按钮开启，预览采用镜像。保持手部可见和稳定光照。

1. 张开手掌向右挥：上一页。
2. 张开手掌向左挥：下一页。
3. 伸出食指向上移动：向上滚动。
4. 伸出食指向下移动：向下滚动。
5. 手背朝向摄像头，仅大拇指伸出，其他四指收起，保持约0.7秒：开始语音。
6. 录音时手背朝向摄像头，同时伸出大拇指和食指，其他三指收起，保持约1秒：停止、完成转写并发送。

动作后回到中立姿势，再执行下一次动作。结束手势只作用于当前正在录音的会话。弹窗、窗口不在前台或识别中断时暂停手势指令。麦克风与摄像头可分别关闭。

## 本地数据与使用边界

API Key 在主进程加密保存，不出现在任务记录或源码中。DeepSeek 仅在你发送或发起生成任务时接收所需材料，原始语音与摄像头画面用于本地推理。公开文献检索会把检索词或引用标识符发送给相应服务。

AI 内容与分类建议存在误解可能。论文原文、图注和网页是资料，不是给 Agent 的权限指令。程序不提供任意命令执行、自动删除文件或绕过全文访问限制。
